# 工作台换肤提示词 · Theme Swap

工作台已内置三套换肤能力（无需再实现），本页提示词用于让 **Agent 帮你改参数 / 加配色 / 调效果**。复制对应段落给任意 AI Agent 即可。

---

## 内置能力速览（开箱即用）

| 能力 | 入口 | 说明 |
|---|---|---|
| 🎨 七色主题 | 侧栏底部「主题色」色票 | 一键换全站品牌色，localStorage 记忆 |
| 🧊 毛玻璃主题 | 侧栏底部「🧊 毛玻璃主题」 | 渐变极光底 + 磨砂玻璃卡片，可开关 |
| ✨ 悬停动效 | 自动生效 | 卡片悬停流光描边 / 按钮悬停流光 / 登录页光束背景 |

三件可叠加：珊瑚橙 + 毛玻璃 + 悬停流光 = 效果最炸组合。

---

## 提示词 ①：换一套自己的品牌色

```
打开 src/theme.ts，BRAND_PRESETS 数组里每套配色是 4 个 HSL 三元组
（brand 主色 / dark 深色 / light 亮色 / tint 浅底）。
请把「默认蓝」那套替换成我的品牌色：
主色 #E44824（其余三值由你按明度关系推导，保持同色相）。
改完刷新工作台，侧栏第一个色票就是我的品牌色。
```

## 提示词 ②：调毛玻璃质感

```
打开 src/styles.css 的 html.glass 主题块，帮我调整毛玻璃质感：
卡片模糊度 blur(18px) → blur(12px)，卡片透明白 0.58 → 0.7（更实、更商务），
背景三层径向光晕的不透明度全部乘 0.7（更淡雅）。
只改这几个数值，其他不动。
```

## 提示词 ③：调动效节奏

```
打开 src/styles.css 的「动效三件套」块：
描边光束转速 3.5s → 5s（更稳重），按钮流光周期 1.8s → 2.4s，
登录页光束漂移 16s → 20s。只改动画时长，不动结构。
```

---

## 参数速查（自己动手改也行）

- 品牌色四元组：`src/theme.ts` → `BRAND_PRESETS`
- 玻璃参数：`src/styles.css` → `html.glass .card`（blur / 透明度 / 投影）
- 动效节奏：`beam-rotate 3.5s` / `shimmer-slide 1.8s` / `beams-drift 16s`
- 动效触发方式：全部悬停触发（`.beam-card:hover::before`），尊重系统"减少动效"设置

> 效果实现取材 [Magic UI](https://magicui.design)（MIT）的 Border Beam / Shimmer Button 设计模式，以纯 CSS 零依赖实现。
